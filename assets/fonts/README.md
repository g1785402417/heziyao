# Fonts

This folder contains self-hosted WOFF2 subsets of:

- **Noto Serif SC** (Google / Adobe) — SIL Open Font License 1.1
- **Noto Sans SC** (Google / Adobe) — SIL Open Font License 1.1
- **Fraunces** (The Fraunces Project Authors) — SIL Open Font License 1.1

Subsets were generated for the characters used on this website and its public CV.
The fonts are not sold or redistributed as standalone font products.
See `OFL.txt` for the license terms.
