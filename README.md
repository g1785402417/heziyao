# 何紫瑶 · 融合教育求职作品集

一个面向融合教育支持、特殊儿童康复与融合幼儿园岗位的个人求职作品集，使用纯 HTML、CSS 和 JavaScript 构建，部署于 GitHub Pages。

**网址：** [https://g1785402417.github.io/heziyao/](https://g1785402417.github.io/heziyao/)

## 页面内容

- 个人简介与支持观
- 教育背景与在校成绩
- 专业能力与已取得资质
- 融合幼儿园见习、课后托管与校园实践
- 荣誉奖励与完整清单
- 职业成长规划
- 联系方式与公开简历下载

## 隐私说明

- 网站仅公开邮箱。
- 不展示手机号、住址、身份证号、出生年月、照片、儿童照片或证书原件扫描件。
- 公开简历为单独制作的脱敏版本，已隐去手机号、住址与照片。
- 原始简历、PPT、证书扫描件均不包含在本仓库中。
- 见习与项目中的支持工作均在带教教师或督导指导下完成，页面表述已避免夸大。

## 技术说明

- 单页响应式设计，适配桌面、平板与手机
- 暖纸色视觉系统、原创排版、内联 SVG 图标与植物主题动效
- 字体（Noto Serif SC、Noto Sans SC、Fraunces）已作本地子集化并随站点发布，无外部字体或 CDN 依赖
- 支持键盘导航、跳过链接、减少动态效果偏好与移动端菜单
- 支持首屏入场、滚动显现、数字滚动、悬浮卡片、指针倾斜、滚动进度与返回顶部

## 素材与许可

- 3D 植物插画基于 [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji) 的 “Potted plant” 素材修改，原项目采用 MIT License；许可和修改说明见 [`assets/img/`](assets/img/)。
- 字体采用 SIL Open Font License 1.1，许可文本见 [`assets/fonts/OFL.txt`](assets/fonts/OFL.txt)。
- 页面布局、配色和动效为本项目原创实现。

## 本地预览

在仓库根目录启动任意静态文件服务器，例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 部署

GitHub Pages 使用 `main` 分支根目录发布。站点入口为根目录的 `index.html`。
